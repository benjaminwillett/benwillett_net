# Personal Website

Static personal website built with plain HTML, CSS, and a little vanilla JavaScript.

## Files

- `index.html`: the whole page, including all content
- `styles.css`: colours, type and responsive layout
- `script.js`: mobile navigation and the contact form

## Edit Content

All text is plain HTML in `index.html`. Each venture is one list item in the Ventures section; copy an existing item to add another.

## Contact Form

The site is static, so the form opens the visitor's email app with the message filled in. The address is set in `script.js` and in the contact list in `index.html`.
