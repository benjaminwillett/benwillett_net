About Ben

I grew up in the UK, moved to Australia in 2002 and later served in the Australian Army Reserve. My work has spanned network consulting, software development, snow sports and education.

I founded Devopty to bring the automation I’d built for production networks to other organisations. Its first product, Netopty, generates as-built network documentation from data collected directly from devices. I’m now building Secopty, which reports on network security and compliance. I also built Fleav, the e-commerce marketplace software behind six board-sports marketplaces.
